# Mimic с генератором OpenCode

[Открыть установку и проверку](https://github.com/antew1/antew/actions/workflows/mimic.yml).

Установка включает Mimic, mitmproxy, Python 3.12 и OpenCode 1.18.35.
OpenCode подключён к Mimic через команду `mimic gen --generator opencode`.
Результат генератора преобразуется из событий JSON в проверенный Python-код.

Источник Mimic: [littledivy/mimic](https://github.com/littledivy/mimic).
Зафиксирован коммит `8cf998ac0b365806d8e522d34107cc504ecaa345`.
Источник OpenCode: [официальный релиз 1.18.35](https://github.com/anomalyco/opencode/releases/tag/v1.18.35).
Контрольная сумма архива проверяется до установки.

## Авторизация

1. Получи свой API-ключ в [OpenCode Console](https://opencode.ai/auth).
2. Открой [секреты репозитория](https://github.com/antew1/antew/settings/secrets/actions).
3. Нажми «New repository secret».
4. В поле «Name» введи `OPENCODE_API_KEY`.
5. В поле «Secret» вставь свой API-ключ.
6. Нажми «Add secret».
7. Открой workflow и нажми «Run workflow» для ветки `main`.

API-ключ передаётся генератору только через защищённый секрет GitHub.
Ключ не записывается в файлы репозитория и не выводится в журнал.

Без ключа проверяются установка, интеграция, HAR и подготовка запроса.
Статус явно сообщает, что авторизация ожидается и генерация ещё не выполнялась.
С ключом workflow создаёт пример Python-клиента и показывает его в итогах запуска.

Выбрана модель `opencode/big-pickle`. На момент настройки она доступна
бесплатно в течение ограниченного периода; условия и доступность определяет OpenCode.
Ручная проба без ключа была отклонена провайдером, поэтому для активации
необходим ключ из OpenCode Console.

## Запуск с телефона

1. Открой ссылку на workflow.
2. При необходимости войди в GitHub.
3. Нажми «Run workflow».
4. Оставь ветку «main» и нажми «Run workflow» ещё раз.
5. Открой новый запуск и прочитай его итог.

Установка выполняется заново на временном сервере GitHub Actions.
Секрет авторизации сохраняется в настройках репозитория для следующих запусков.

## Собственное приложение

Для создания клиента нужны записанные запросы: HAR, cURL или захват через mitmproxy.
Проверка использует тестовый HAR из исходного Mimic с адресом `api.example.com`.
Для захвата запросов с телефона нужен компьютер или сервер, доступный телефону как прокси.

Свои записи запросов обрабатывай в приватной среде: HAR может содержать
токены входа и персональные данные. Во время бесплатного периода Big Pickle
провайдер может использовать отправленные данные для улучшения модели.

## Конфигурация

- `.github/workflows/mimic.yml` устанавливает инструмент и проверяет интеграцию.
- `toolchain/mimic/opencode.json` выбирает модель и загрузку ключа из окружения.
- `scripts/mimic_opencode.py` возвращает Mimic только Python-код генератора.
- `toolchain/mimic/test_opencode_adapter.py` проверяет обработку ответа и ошибок.

Генератор получает подготовленный запрос. В конфигурации отключены инструменты,
запуск дополнительных агентов и публикация сессий.
