# Mimic на GitHub

Источник: [littledivy/mimic](https://github.com/littledivy/mimic).
Зафиксирован исходный коммит `8cf998ac0b365806d8e522d34107cc504ecaa345`.

[Открыть установку и проверку](https://github.com/antew1/antew/actions/workflows/mimic.yml).

## Запуск с телефона

1. Открой ссылку на установку и проверку.
2. При необходимости войди в свой GitHub.
3. Нажми «Run workflow».
4. Оставь ветку «main» и нажми «Run workflow» ещё раз.
5. Открой появившийся запуск. Успешное завершение отмечается «Success».

Workflow устанавливает Python 3.12, исходный Mimic, mitmproxy, uv и pytest.
Проверяются запуск команд, встроенные тесты и обработка тестового HAR.
Установка выполняется на временном сервере GitHub Actions при каждом запуске.

## Использование для своего приложения

Mimic создаёт Python-клиенты по захваченным HTTP-запросам.
Для своих запросов используются mitmproxy, HAR или скопированный cURL.
Для генерации кода нужен Claude Code либо OpenCode с авторизацией;
режим `--prompt-only` подготавливает запрос без вызова генератора.

GitHub Actions здесь проверяет готовность инструмента. Для записи запросов
с телефона нужен компьютер или сервер, доступный телефону как прокси.
Проверка использует только тестовый HAR из исходного Mimic.

HAR может содержать токены входа и персональные данные.
Собственные записи нужно обрабатывать в приватной среде.

## Версия и обновление

Установка идёт из исходного проекта, а не из одноимённых Python-пакетов.
Обновление исходного коммита выполняется явно в
`.github/workflows/mimic.yml`, чтобы результат проверки можно было повторить.
